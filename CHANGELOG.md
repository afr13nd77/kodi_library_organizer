# Kodi Library Organizer — Журнал изменений

## [1.3.0] — 27.08.2026

### Добавлено
- Добавление года в имя файла при переносе/копировании (BL-10)
  - Если год известен, но отсутствует в имени файла — вставляет ` (YYYY)` перед расширением
  - Применяется и к видеофайлам, и к ассоциированным файлам (субтитры, NFO)
  - Настройка `rename_files` (включена по умолчанию)
- Рекурсивное сканирование вложенных директорий (BL-04)
  - Сканирование всех уровней вложенности при `recursive_scan=true`
  - Исключение destination-директории при рекурсивном обходе
  - Настройка `recursive_scan` (выключена по умолчанию для обратной совместимости)
- 21 новый тест (195 тестов всего)

## [1.2.0] — 27.08.2026

### Добавлено
- Подстановка года из библиотеки Kodi (JSON-RPC VideoLibrary.GetMovies) для файлов без года в имени (BL-09)
- Настройка "Enrich year from Kodi library" (включена по умолчанию)
- Матчинг по полному пути файла с нормализацией (Windows-совместимо)
- Graceful degradation: ошибки JSON-RPC не блокируют organize
- 5 новых тестов на обогащение года (174 теста всего)

## [1.1.0] — 27.08.2026

### Изменено
- UX: экран подтверждения путей перед сканированием (Source/Destination/Mode + кнопки Continue/Change/Cancel) (BL-08)
- UX: экран подтверждения операции с саммари (кол-во фильмов, файлов, размер) вместо обязательного textviewer (BL-08)
- Просмотр полного списка операций теперь опционален — по кнопке "Details"
- Кнопка "Change" на экране путей открывает Settings и возвращает с обновлёнными значениями

### Добавлено
- 3 новых теста на новый UI-флоу (169 тестов всего)

## [1.0.2] — 27.08.2026

### Исправлено
- Парсер имён: общее правило отсечения — при отсутствии года всё после первого quality-тега отбрасывается целиком, а не поштучно. Исправляет некорректные имена папок для релизов типа LostFilm.TV
- Dual-mode импорты в shared-модулях (flat для Kodi runtime, relative для dev/тестов)

### Добавлено
- 2 новых теста на truncation-логику парсера (166 тестов всего)

## [1.0.0] — 27.08.2026

### Добавлено
- Полный MVP аддона Library Organizer (BL-01)
- shared/file_patterns.py — константы расширений и паттерны (16 видео, 7 субтитров, 7 артворк)
- shared/logger.py — логирование с fallback для среды без Kodi
- shared/name_parser.py — парсинг имён файлов (title, year, clean folder name)
- shared/undo_journal.py — журнал операций для отката (JSON, version 1)
- shared/scanner.py — сканирование директории, группировка файлов, multi-part
- shared/organizer.py — планирование и выполнение move/copy, конфликт-резолюция
- script.library.organizer/python/main.py — Kodi UI точка входа
- addon.xml, settings.xml — манифест и 9 настроек (3 категории)
- Локализация: en_GB + ru_RU (24 строки)
- build_zip.py — сборка ZIP-пакета аддона
- ruff.toml — линтер (Python 3.8, line-length 120)
- CI pipeline — lint → test → build → release (.github/workflows/ci.yml)
- 164 теста (152 shared + 12 main.py)

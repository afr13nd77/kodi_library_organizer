# BL-01: Реорганизация фильмотеки в per-folder структуру

**Статус:** draft
**Приоритет:** MVP (v1.0)

---

## 1.1 Обзор

Kodi-аддон типа `xbmc.python.script`, который переносит фильмы из плоской директории (все файлы в одном каталоге) в структуру "каждый фильм в своей папке" (per-folder). Это необходимо при переходе между режимами хранения в настройках источников Kodi, где тип хранения — свойство всей директории, а не отдельного файла.

**Пользователь:** владелец домашней медиатеки Kodi, решивший перейти на per-folder хранение.

**Проблема:** ручное создание папок и перемещение сотен файлов — рутинная и error-prone операция. Нужно правильно сгруппировать видео + субтитры + NFO + артворк, создать папки с нормализованными именами, не потерять файлы.

---

## 1.2 User Stories

```
US-01: Как пользователь Kodi, я хочу выбрать папку-источник (плоская библиотека) 
       и папку назначения, чтобы автоматически реорганизовать фильмы в per-folder структуру.

US-02: Как пользователь, я хочу увидеть превью планируемых операций (dry-run) 
       перед реальным перемещением, чтобы убедиться что всё корректно.

US-03: Как пользователь, я хочу выбрать между копированием и перемещением файлов,
       чтобы управлять использованием дискового пространства.

US-04: Как пользователь, я хочу иметь возможность отменить (откатить) операцию,
       если результат меня не устроил.

US-05: Как пользователь, я хочу чтобы папки назывались в формате "Название (Год)", 
       даже если файлы называются "Movie.Name.2014.1080p.BDRip.mkv",
       а файлы внутри сохраняли оригинальные имена.
```

---

## 1.3 User Flows

### FLOW-01: Основной сценарий — реорганизация библиотеки

```
1. Пользователь открывает аддон из меню "Программы" в Kodi
2. Аддон показывает главное меню с действиями:
   - "Организовать библиотеку"
   - "Откатить последнюю операцию"
   - "Настройки"
3. Пользователь выбирает "Организовать библиотеку"
4. Аддон открывает диалог выбора папки-источника
   → Пользователь выбирает папку с плоской библиотекой
5. Аддон открывает диалог выбора папки назначения
   → Пользователь выбирает целевую папку (может быть пустой или с существующими фильмами)
6. Аддон сканирует source-директорию:
   - Находит все видеофайлы
   - Группирует связанные файлы (субтитры, NFO, артворк) по базовому имени
   - Фильтрует файлы меньше порога (sample/trailer)
   - Парсит имена файлов → извлекает название и год для имени папки
7. Аддон показывает превью (dry-run):
   - Список операций: "Movie.Name.2014.1080p.mkv → Название (2014)/Movie.Name.2014.1080p.mkv"
   - Общая статистика: N фильмов, M файлов, X GB
   - Файлы без распознанного названия/года (требуют внимания)
   → CANCEL: возврат в главное меню
   → CONFIRM: переход к выполнению
8. Аддон выполняет операции:
   - Создаёт папки в destination
   - Перемещает/копирует файлы (согласно настройке operation_mode)
   - Записывает каждую операцию в undo-журнал
   - Показывает прогресс-бар с возможностью отмены
   → SUCCESS: "Готово. Организовано N фильмов (M файлов). 
              Не забудьте обновить источники в настройках Kodi."
   → CANCEL (mid-operation): завершить текущий файл, 
              показать "Операция прервана. Перемещено X из Y фильмов. 
              Используйте 'Откатить' для возврата."
   → ERROR (нет места на диске): остановить, показать ошибку,
              предложить откат уже перемещённых файлов
```

### FLOW-02: Dry-run (превью)

```
1. Аддон сканирует source → строит план операций
2. Показывает текстовый список (xbmcgui.Dialog.textviewer):
   --- Превью операций ---
   Режим: Перемещение
   Источник: /media/movies/
   Назначение: /media/movies_organized/

   [1] Interstellar.2014.1080p.BDRip.mkv (4.2 GB)
       + Interstellar.2014.1080p.srt
       + Interstellar.2014.1080p.nfo
       → Interstellar (2014)/

   [2] Dune.Part.Two.2024.WEB-DL.mkv (2.8 GB)
       + Dune.Part.Two.2024.WEB-DL.srt
       → Dune Part Two (2024)/

   [!] sample_video.avi (45 MB) — пропущен (меньше 100 MB)

   Итого: 2 фильма, 5 файлов, 7.0 GB
   ---
3. Пользователь решает: выполнить или отменить
```

### FLOW-03: Откат операции

```
1. Пользователь выбирает "Откатить последнюю операцию" в главном меню
2. Аддон читает последний undo-журнал
   → ЖУРНАЛ НЕ НАЙДЕН: "Нет операций для отката"
   → ЖУРНАЛ НАЙДЕН: показать сводку "Откатить операцию от [дата]? 
                     N фильмов будут возвращены в [source path]"
3. Пользователь подтверждает
4. Аддон выполняет обратные операции:
   - Перемещает файлы обратно из destination в source
   - Удаляет пустые папки в destination
   - Показывает прогресс
   → SUCCESS: "Откат завершён. Файлы возвращены в [source path]"
   → PARTIAL ERROR: "Откат частично завершён. Не удалось вернуть: [список]"
```

### FLOW-04: Multi-part фильмы

```
1. Сканер находит файлы с паттерном multi-part:
   - Movie.Name.CD1.avi, Movie.Name.CD2.avi
   - Movie.Name.Part.1.mkv, Movie.Name.Part.2.mkv
2. Группирует их в одну запись
3. В превью показывает как один фильм:
   [3] Movie.Name.CD1.avi (700 MB)
       + Movie.Name.CD2.avi (700 MB)
       + Movie.Name.srt
       → Movie Name/
4. Оба файла перемещаются в одну папку
```

### FLOW-05: Конфликты

```
1. При создании папки в destination обнаруживается, что папка уже существует
   (например, пользователь запускает повторно или часть фильмов уже организована)
2. Аддон показывает диалог:
   "Папка 'Interstellar (2014)' уже существует в назначении.
    [Пропустить] [Объединить] [Переименовать → Interstellar (2014)_2]"
3. Если выбрано "Объединить" и файл с таким именем уже есть внутри:
   "Файл 'movie.mkv' уже существует.
    [Пропустить файл] [Заменить] [Переименовать]"
```

## 1.4 Acceptance Criteria

### US-01: Выбор папок и организация

```
AC-01 (US-01):
  GIVEN: аддон запущен, source содержит 5 видеофайлов с субтитрами и NFO
  WHEN: пользователь выбирает source и destination, подтверждает выполнение
  THEN: в destination создаётся 5 папок
        AND каждая папка содержит видеофайл + связанные файлы
        AND имена папок в формате "Название (Год)" (если год распознан)
        AND имена файлов внутри папок не изменены
        AND source-директория пуста (при режиме Move) или не изменена (при режиме Copy)

AC-02 (US-01):
  GIVEN: source содержит видеофайл с 3 субтитрами (.srt, .sub, .ass),
         1 NFO и 2 артворками (-poster.jpg, -fanart.jpg)
  WHEN: выполняется организация
  THEN: все 7 файлов (видео + 6 связанных) перемещены в одну папку
        AND ни один связанный файл не потерян

AC-03 (US-01):
  GIVEN: source содержит файл sample.avi размером 45 MB,
         настройка min_file_size_mb = 100
  WHEN: выполняется сканирование
  THEN: sample.avi не включён в план операций
        AND в превью отмечен как "пропущен"

AC-04 (US-01):
  GIVEN: source и destination — один и тот же путь
  WHEN: пользователь пытается начать операцию
  THEN: аддон показывает ошибку "Источник и назначение не могут совпадать"
        AND операция не выполняется
```

### US-02: Dry-run (превью)

```
AC-05 (US-02):
  GIVEN: настройка dry_run включена (по умолчанию)
  WHEN: пользователь запускает организацию
  THEN: показывается текстовое превью со списком всех планируемых операций
        AND ни один файл не перемещён/скопирован
        AND ни одна папка не создана в destination

AC-06 (US-02):
  GIVEN: dry-run показывает превью для 10 фильмов
  WHEN: пользователь подтверждает выполнение
  THEN: аддон выполняет ровно те операции, которые были показаны в превью
        AND никаких дополнительных/пропущенных операций
```

### US-03: Режим копирования/перемещения

```
AC-07 (US-03):
  GIVEN: operation_mode = Move, source и destination на одном диске
  WHEN: выполняется организация файла 4 GB
  THEN: файл перемещён (не скопирован) — операция занимает менее 1 секунды
        AND файл отсутствует в source
        AND файл присутствует в destination

AC-08 (US-03):
  GIVEN: operation_mode = Copy
  WHEN: выполняется организация
  THEN: все файлы присутствуют и в source, и в destination
        AND размеры совпадают

AC-09 (US-03):
  GIVEN: operation_mode = Copy, на диске destination недостаточно места
  WHEN: копирование достигает лимита
  THEN: аддон останавливается с ошибкой "Недостаточно места на диске"
        AND показывает сколько фильмов успешно скопировано
        AND не оставляет частично скопированных файлов
```

### US-04: Откат

```
AC-10 (US-04):
  GIVEN: организация выполнена (mode = Move), undo-журнал существует
  WHEN: пользователь выбирает "Откатить последнюю операцию"
  THEN: все файлы возвращены в source по оригинальным путям
        AND пустые папки в destination удалены
        AND undo-журнал помечен как использованный

AC-11 (US-04):
  GIVEN: организация выполнена (mode = Copy)
  WHEN: пользователь выбирает "Откатить"
  THEN: копии в destination удалены
        AND пустые папки в destination удалены
        AND файлы в source не затронуты

AC-12 (US-04):
  GIVEN: после организации пользователь вручную переименовал/удалил 
         некоторые файлы в destination
  WHEN: выполняется откат
  THEN: файлы, которые ещё на месте — откатываются
        AND для файлов, которых нет — выводится предупреждение
        AND откат завершается с отчётом "Откачено X из Y файлов"
```

### US-05: Нормализация имён папок

```
AC-13 (US-05):
  GIVEN: видеофайл "Interstellar.2014.1080p.BDRip.x264.mkv", clean_names = true
  WHEN: выполняется организация
  THEN: создаётся папка "Interstellar (2014)"
        AND файл внутри сохраняет оригинальное имя "Interstellar.2014.1080p.BDRip.x264.mkv"

AC-14 (US-05):
  GIVEN: видеофайл "Dune.Part.Two.2024.WEB-DL.mkv", clean_names = true
  WHEN: выполняется организация
  THEN: создаётся папка "Dune Part Two (2024)"

AC-15 (US-05):
  GIVEN: видеофайл "some_random_movie.mkv" (год не распознан), clean_names = true
  WHEN: выполняется организация
  THEN: создаётся папка "some_random_movie" (используется базовое имя файла без расширения)
        AND файл отмечен в превью как "год не распознан"

AC-16 (US-05):
  GIVEN: clean_names = false
  WHEN: выполняется организация файла "Interstellar.2014.1080p.BDRip.x264.mkv"
  THEN: создаётся папка "Interstellar.2014.1080p.BDRip.x264" 
        (базовое имя файла без расширения, без нормализации)
```

## 1.5 Out of Scope (MVP)

- **CLI-интерфейс** — только Kodi-аддон, без standalone режима (BL-02)
- **Обратная операция** — из per-folder в плоскую (BL-03, кроме undo последней операции)
- **Рекурсивное сканирование** — только верхний уровень source-директории (BL-04)
- **Нормализация имён файлов** — файлы сохраняют оригинальные имена (BL-05)
- **Интеграция с UMS/скраперами** — аддон не запускает скрейпинг (BL-06)
- **Обновление Kodi DB** — аддон не модифицирует базу Kodi напрямую, пользователь сам обновляет источники
- **TV-шоу** — только фильмы
- **Обработка disc images** (VIDEO_TS, BDMV) — только одиночные видеофайлы

## 1.6 Зависимости

### Внешние
- **Kodi v20+** — runtime-окружение (Python 3.8, xbmc* API)
- **Файловая система** — стандартные os/shutil операции, xbmcvfs для Kodi-специфичных путей (SMB, NFS)

### Внутренние
- Нет зависимостей на другие проекты. Аддон полностью самодостаточен.

### Техническая совместимость
- Python 3.8 (ограничение Kodi v20) → `from __future__ import annotations`
- Нет внешних pip-зависимостей — только stdlib + Kodi API
- Кроссплатформенность: Windows, Linux, Android, macOS (Kodi работает на всех)
